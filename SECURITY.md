# Security Policy

## Supported Versions

Marvel Champions Digital (MCD) is an actively developed open-source client application. Security updates and patches are applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x (latest `main`)   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of our codebase and user data seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

### Reporting Process
1. **Private Disclosure:** Please report security vulnerabilities by creating a **Private Vulnerability Report** on GitHub under the **Security** tab of the repository (`https://github.com/SteveRodrigue/MCD/security/advisories/new`), or by emailing the project maintainers directly.
2. **Details to Include:**
   * Description of the vulnerability.
   * Steps to reproduce or proof-of-concept payload.
   * Potential impact on user sessions, local storage, or network security.
3. **Response Timeline:**
   * We will acknowledge receipt of your report within **48 hours**.
   * We will provide a status update or fix timeline within **7 days**.
   * Once a patch is released, we will publicly credit the reporter (unless you prefer to remain anonymous).

---

## Scope & Guidelines

* MCD is an offline-capable, client-side web and desktop application.
* Safe testing practices are encouraged; please do not engage in activities that disrupt community services or third-party APIs (such as MarvelCDB image CDNs).

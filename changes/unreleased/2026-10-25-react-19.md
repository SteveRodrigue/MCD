- **UI: Upgraded React and React DOM to 19.3.1, with `@types/react` and `@types/react-dom` 19.3.0 (Dependabot PR #399)**
  - The repo used none of the removed React APIs (`defaultProps`, `propTypes`, `ReactDOM.render`, `react-dom/test-utils`, string refs). Two code changes were needed: `useHandFanLayout` types its container ref as nullable, and `LabSidebar` takes `ref` as a prop instead of `React.forwardRef`.
  - Dependabot now groups `react`, `react-dom` and the two `@types` packages into one PR, because `react-dom` 19 cannot install against React 18 (PR #399 opened as `react-dom` alone).

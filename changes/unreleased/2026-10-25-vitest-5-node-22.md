- **Tooling: Upgraded Vitest and `@vitest/coverage-v8` to 5.0.5 and moved CI to Node 22 (Dependabot PRs #392, #395)**
  - Vitest 5 requires Node `^22.12 || ^24 || >=26`, so the CI workflow now runs Node 22 instead of 20.
  - `@vitest/coverage-v8` pins the exact `vitest` version, so Dependabot now groups the two into one PR.
  - The `typescript` 7.0.2 bump (PR #391) is not taken: `@typescript-eslint` supports only TypeScript below 6.1.0, so lint cannot install with it.

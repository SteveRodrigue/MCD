- **Feature (UI): Hero and alter-ego art packs proved with a full pack ([Issue #618](https://github.com/SteveRodrigue/MCD/issues/618))**
  - Every identity card has its image in a full fan-made pack, and both faces of each hero load when the game starts, so the first form change has no wait.
  - A card from an installed pack that is off is no longer reported as a problem. Browse names it and marks it "pack off", and the filter finds it. Only a code in no installed pack gets a warning.

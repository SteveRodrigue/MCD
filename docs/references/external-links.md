# External Card Game Rules & Rulings References

This document captures primary authoritative links, community databases, and card-specific discussion resources for **Marvel Champions Digital (MCD)** developers.

---

## 1. Primary Rules & Errata References

| Resource | URL | Purpose / Usage |
| :--- | :--- | :--- |
| **MarvelCDB Official FAQs & Errata** | [https://marvelcdb.com/faqs](https://marvelcdb.com/faqs) | Official FAQ answers, timing clarifications, and errata text for cards. |
| **MarvelCDB Card Explorer & Discussion** | `https://marvelcdb.com/card/{{ #card }}`<br/>_Example:_ [https://marvelcdb.com/card/01002](https://marvelcdb.com/card/01002) | Individual card pages containing user reviews, ruling discussions, and edge-case interpretations. |
| **Fantasy Flight Games (FFG) Official Rules** | [FFG Marvel Champions Support](https://www.fantasyflightgames.com/en/products/marvel-champions-the-card-game/) | Official PDF Rules Reference (v1.8) and Learn to Play documents. |
| **Hall of Heroes Rulings Archive** | [https://hallofheroeslcg.com/latest-ffg-rulings/](https://hallofheroeslcg.com/latest-ffg-rulings/) | Developer Q&A and official email ruling logs from FFG game designers. |

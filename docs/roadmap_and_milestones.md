# Marvel Champions Digital (MCD) — Roadmap

The goals of the project, in order. **For status, open issues and the work in each gate, refer to [GitHub milestones](https://github.com/SteveRodrigue/MCD/milestones).**

This file is deliberately coarse. It records no status, issue or progress, and it changes only when a goal changes.

## Goals

| Gate                                                                                         | Goal                                                                                         |
| :------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------- |
| [Gate 1 — Rhino Release](https://github.com/SteveRodrigue/MCD/milestone/2)                   | A complete, rules-verified game: the 5 Core heroes against Rhino, on Standard and Expert.    |
| [Gate 2 — Klaw & Ultron](https://github.com/SteveRodrigue/MCD/milestone/3)                   | The remaining Core Set: Klaw, Ultron, the Core modular sets, and scenarios as plug-ins.      |
| [Gate 3 — Green Goblin (MC02)](https://github.com/SteveRodrigue/MCD/milestone/4)             | The MC02 scenario pack: Risky Business and Mutagen Formula, with double-sided villains.      |
| [Gate 4 — Wrecking Crew (MC03)](https://github.com/SteveRodrigue/MCD/milestone/5)            | The MC03 scenario pack: several villains at once, each with its own deck and schemes.        |
| [Gate 5 — Expansions & Advanced Mechanics](https://github.com/SteveRodrigue/MCD/milestone/7) | The advanced mechanics that later expansions need.                                           |
| [Undetermined — Multiplayer Co-op](https://github.com/SteveRodrigue/MCD/milestone/8)         | Far future: 2 to 4 players at one table, with Alliance, Team-Up and triggers across players. |

Two milestones run alongside the gates, and no gate depends on them: [Tech Debt & Tooling](https://github.com/SteveRodrigue/MCD/milestone/6) and [UI theming](https://github.com/SteveRodrigue/MCD/milestone/9).

## How the gates work

- Gates run in order. The active gate is the open `Gate N` milestone with the lowest N that still has open issues.
- Every open issue belongs to exactly one milestone. New issues get one at triage.

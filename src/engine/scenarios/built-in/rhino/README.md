## Special Rules & Stage Transitions
1. **Stage II When Revealed (`01095`):** Search the encounter deck and discard pile for *Breakin' & Takin'* (`01107`) and reveal it. Shuffle the encounter deck.
2. **Stage III When Revealed (`01096`):** Stun each hero. Rhino gains *Tough*.
3. **Main Scheme Defeat (`01097b`):** If *The Break-In!* reaches $7 \times P$ threat, the players immediately lose the game.
